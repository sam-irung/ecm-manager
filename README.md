# ECM Manager

Application de gestion pour **ECM — Équipe de Construction Moderne**.

## Fonctionnalités

- 🔐 Authentification (multi-utilisateurs, base partagée)
- 👥 Gestion des clients
- 📄 Devis avec calcul automatique FC/USD
- 🖨️ Génération PDF des devis
- 🏗️ Chantiers (suivi, statuts)
- 💰 Paiements et dépenses
- 📊 Tableau de bord et statistiques
- 📦 Catalogue de produits

## Stack technique

- **Next.js 16** (App Router, Turbopack)
- **TypeScript**
- **Tailwind CSS**
- **Prisma ORM** (PostgreSQL)
- **Supabase** (base de données hébergée)
- **Auth.js v5** (NextAuth)
- **@react-pdf/renderer** (génération PDF)
